## Line Follower Robot (POP32)

## Overview
This project is a line follower robot developed using POP32 and Arduino IDE with PID Control.

## Features
- PID Control
- 9 Analog Sensors
- Adaptive Speed Control
- Automatic Line Tracking

## Hardware
- POP32
- DC Motors
- IR Sensor Array
- Motor Driver

## Programming
- Arduino IDE
- C++
